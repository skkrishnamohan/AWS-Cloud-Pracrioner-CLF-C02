# AWS Cloud Practitioner Notes (CLF-C02)

Beginner-friendly study notes written like **session notes from an AWS Cloud Practitioner course**, aligned with the **official CLF-C02 exam guide** (updated through 2026).

## Exam at a glance

| Item | Detail |
|------|--------|
| Exam code | **CLF-C02** (current foundational exam) |
| Format | 65 questions total — **50 scored**, 15 unscored (you won’t know which) |
| Question types | Multiple choice (one answer) and multiple response (two or more correct) |
| Time | 90 minutes |
| Passing score | **700** on a scale of 100–1000 |
| Who it’s for | Anyone new to cloud; ~0–6 months AWS exposure is enough to start |

**Four domains (scored weightings):**

1. **Cloud Concepts** — 24%
2. **Security and Compliance** — 30%
3. **Cloud Technology and Services** — 34%
4. **Billing, Pricing, and Support** — 12%

Official reference: [AWS Certified Cloud Practitioner (CLF-C02) exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html)

## What this repo is / isn’t

- **Is:** Plain-language explanations, analogies, and “what to remember for the exam” callouts tied to CLF-C02 task statements.
- **Isn’t:** A replacement for hands-on labs in AWS Free Tier, official practice questions, or deep implementation guides.

Good luck — and take breaks. Cloud vocabulary gets easier once you see the same services in the console a few times.
